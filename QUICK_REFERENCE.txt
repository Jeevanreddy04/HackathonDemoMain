## API Changes

### Request Format (New)
```json
{
  "teamLeadName": "John Doe",
  "email": "john.doe@htcinc.com",
  "problemStatementId": 1
}
```

### Success Response
```json
{
  "success": true,
  "message": "User registered successfully! Your ID: USER_20240115_45678"
}
```

### Error Response
```json
{
  "success": false,
  "message": "Email must end with @htcinc.com"
}
```

## Code Patterns Used

### Auto-ID Generation (Backend)
```java
@PrePersist  // Called before save
protected void onCreate() {
    userId = "USER_" + timestamp + "_" + random;
}
```

### Email Validation (Frontend)
```javascript
const regex = /^[^\s@]+@htcinc\.com$/;
if (!regex.test(email)) { /* error */ }
```

### Unique Constraint (Database)
```java
@UniqueConstraint(columnNames = "email")
```
